# Request Type
ada beberapa jenis request dari Staff to Admin:
1. Pengadaan barang
1.1 Pengadaan barang jika barang sudah ada tapi jumlah tidak cukup (pengadaan jumlah)
1.2 Pengadaan barang jika barang belum pernah ada sama sekali
2. Penggunaan barang. barang sudah ada jumlah mencukupi dan staff request ke admin untuk menggunakan barang tersebut dengan jumlah tertentu dan tidak bisa melewati jumlah yang tersedia
